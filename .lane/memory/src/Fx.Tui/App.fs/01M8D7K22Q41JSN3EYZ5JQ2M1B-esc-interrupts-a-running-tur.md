Esc interrupts a running turn before anything but the modes Esc closes (the palette, selecting items): scrolling back to the end never takes Esc while a turn runs (PgDn, the wheel and Ctrl+End do). Ctrl+Home/Ctrl+End are the transcript's; plain Home/End stay the prompt's (while selecting items, they select the oldest and the newest).
