# kernel-bun-ts: the bun-ts kernel

The kernel of `fx.interpreter.bun-ts` ([`extensions/Fx.Ext.InterpreterBunTs`](../../extensions/Fx.Ext.InterpreterBunTs),
[`docs/modules/interpreters.md`](../../docs/modules/interpreters.md)): TypeScript cells in a persistent
kernel on the pinned Bun. It is also the reference implementation of the kernel protocol
([`docs/modules/kernel-protocol.md`](../../docs/modules/kernel-protocol.md)), which the conformance
suite (`tests/Fx.Kernel.Tests`) runs against on Linux, macOS, Windows and musl.

It grew out of the Bun kernel spike ([`spikes/bun-kernel`](../../spikes/bun-kernel),
[`docs/spikes/bun-kernel.md`](../../docs/spikes/bun-kernel.md)): the same transpile, `node:vm` and
`bun check` design, upgraded to the protocol. The spike stays as it was, as the record of what was
measured.

```sh
bun install --frozen-lockfile
bun check --no-script   # type-check (with the generated protocol types)
bun test                # unit tests of previews, values, output, the checker and the globals
```

**The sources are what ships.** The binary carries `src/*.ts` (all but `protocol.d.ts`) as
`extensions/Fx.Ext.InterpreterBunTs/KernelFiles.fs`, generated by that package's tests: after a change
here, run `UPDATE_GOLDEN=1 dotnet test --project tests/Fx.Ext.InterpreterBunTs.Tests`, rebuild, and
run the kernel conformance suite (`dotnet test --project tests/Fx.Kernel.Tests`). The host extracts
the files with hash checks and starts `main.ts` with `fx.runtime.bun`'s hardened launch; it never runs
a Bun from `PATH`. Keep the files flat, without dependencies (only `node:*` and Bun's own modules).

| Path | Contents |
|---|---|
| `src/protocol.d.ts` | The protocol's messages, **generated** from the F# codecs (`Fx.Kernel.KernelDeclarations`). Do not edit: change the codecs and run the tests with `UPDATE_GOLDEN=1` |
| `src/rpc.ts` | JSON-RPC as the host speaks it: the `initialize` handshake, `$/cancelRequest` both ways, error codes, frames on lines of their own |
| `src/kernel.ts` | Cells, the host bridge global, values, cancellation, `cell/check` |
| `src/checker.ts` | Type-checking cells with `bun check --no-script` against the bridge's declarations and earlier cells |
| `src/globals.ts` | The cells' globals and their declarations, from one table |
| `src/values.ts` | `Value` decode and encode (references held in WeakMaps, so cells cannot forge them), bounded previews |
| `src/output.ts` | Bounded output (head and tail) and streamed output |
| `src/positions.ts` | Stack positions mapped back to cell lines (from the spike; replMode has no source maps) |
| `src/main.ts` | The process: arguments (`--bindings=<dir>`, `--check-dir=<dir>`), stdio, output capture |

- `Out[cellId]` holds each cell's completion value; `recall` restores entries after a restart.
- Cells can report activity with `<global>.activity(kind, title, detail?)`; wrappers that report it for
  the bindings are T205's.
- Content exclusions are the host's: `fs.read` refuses excluded files (docs/modules/egress.md).
